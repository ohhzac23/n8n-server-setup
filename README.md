## n8n 服务器配置完整步骤：从裸机到打开后台

全程半小时以内，五步。

1. **装系统**：在 RackNerd 的面板里把系统重装成 Ubuntu 22.04 或 Debian 12
2. **装 Docker**：按 Docker 官方安装脚本一条命令搞定
3. **创建数据卷**：`docker volume create n8n_data`
4. **启动容器**（先用 IP 调通）：

bash
docker run -d --name n8n \
  -p 5678:5678 \
  -v n8n_data:/home/node/.n8n \
  -e GENERIC_TIMEZONE=Asia/Shanghai \
  -e N8N_SECURE_COOKIE=false \
  n8nio/n8n


5. 浏览器访问 `http://服务器IP:5678`，出现注册页面就是成功了

这里有个教程里很少讲透的坑：`N8N_SECURE_COOKIE=false` 的意思是“允许非 HTTPS 环境的 Cookie”。用 IP+HTTP 访问的阶段必须加，否则登录页会卡在 Cookie 报错上；等绑好域名上了 HTTPS，就要去掉这一行重建容器。数据在 volume 里，重建不会丢。

防火墙记得放行 22、80、443 三个端口，5678 调通之后下一步会把它收回去。

## 绑域名和 HTTPS：两条环境变量别填错

用 Caddy 做反向代理，三行配置自动签发证书：

caddyfile
n8n.example.com {
    reverse_proxy localhost:5678
}


Caddy 会自动申请和续期 Let's Encrypt 证书，不用手动管。习惯用面板的话，1Panel 里创建“反向代理”类型的网站、代理地址填 `http://localhost:5678/` 也一样——结尾的斜杠不能省，省了会有 WebSocket 连接问题，这是面板部署最常见的翻车点。用面板申请 ACME 证书的话，自动续签的勾一定要选上，不然每三个月要手动折腾一次。

然后重建容器，环境变量换成这样：

bash
docker run -d --name n8n \
  -p 127.0.0.1:5678:5678 \
  -v n8n_data:/home/node/.n8n \
  -e N8N_HOST=n8n.example.com \
  -e WEBHOOK_URL=https://n8n.example.com/ \
  -e GENERIC_TIMEZONE=Asia/Shanghai \
  -e N8N_PROXY_HOPS=1 \
  -e N8N_RUNNERS_ENABLED=true \
  --restart always \
  n8nio/n8n


三个细节：

- `N8N_HOST` 填不带协议头的域名，`WEBHOOK_URL` 填带 https:// 的完整地址，两个变量就差在协议头上，别混
- `N8N_PROXY_HOPS=1` 表示 n8n 在一层反向代理后面，填错会影响它识别真实访客 IP
- 端口映射改成 `127.0.0.1:5678:5678` 之后，5678 只对本机开放，公网只能走 443，安全性上一个台阶

## 开通之后，先做这三件事

部署完不等于结束，这三件事比部署本身还重要。

1. 记好超级管理员的账号密码。私有部署的 n8n 没有找回密码功能，忘了只能删掉数据重来
2. 立刻定好备份。工作流、加密后的凭证、执行历史全在挂载的 volume（默认路径 /home/node/.n8n）里，定期把这个目录拉下来，整套 n8n 就丢不了
3. 敏感信息进文件。数据库密码这类配置可以在环境变量名后加 `_FILE` 后缀，让 n8n 从文件里读，避免密钥明文出现在进程环境里

## 常见问题

**768MB 内存的套餐能跑 n8n 吗？**
能启动、能进后台，跑一两个轻工作流也可以，但拉镜像或跑重工作流时容易内存告急，只建议拿来做实验，长期用请上 1.5GB。

**RackNerd 的服务器需要备案吗？**
不需要。备案只针对国内服务器，海外 VPS 配海外域名直接就能用，而且没有国内节点访问不了 Google、OpenAI 的麻烦。

**可以装 1Panel 或宝塔面板吗？**
可以，面板加 Docker 的实际占用不大，但 1.5GB 以上内存会从容很多。用 1Panel 部署就是拉取 n8nio/n8n 镜像、挂载数据目录、创建反向代理网站这三步，和命令行殊途同归。

**n8n 界面有中文吗？**
新版编辑器内置了多语言，加环境变量 `N8N_DEFAULT_LOCALE=zh-CN` 可以把默认语言设成中文；想要更彻底的汉化，社区有替换 editor-ui 静态文件的汉化包，代价是每次升级版本都要重做一遍。
